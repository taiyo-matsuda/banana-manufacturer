# 設計: 画面

最終更新: 2026-10-25（UX-1: 3 章「共通」を部品とナビの決まりで更新）　要件: `../01_requirements.md` 6章

スマホ（iPhone、PWA、ホーム画面に追加）を優先し、PC でも同じ画面を使う。
下部に固定タブ（ホーム / 地図 / 予測 / 設定）。記録系の画面は地図から株 → 茎とたどる。

## 2. 画面の詳細

### 1. ホーム / 今週の巡回
- 上部: 未同期件数（0 でも表示）。タップで同期の状態と失敗分を見る
- 「今週見る株」: 前回観測からの経過日数、積算温度、出蕾予想の近さで並べる。タップで株の詳細へ
- 「提案」: `recommendations` の `open` を期限順に。各行に「実施した」「無視」ボタン
- 圃場が複数あるときは圃場で絞り込める（既定は全圃場）

### 2. 圃場マップ
- MapLibre。下地は地理院タイル（空中写真）。画面下に出典「地理院タイル（国土地理院）」を常時表示
- 株は点で表示。色は最も進んだ茎の状態（栽培中 / 出蕾済み / 収穫済み / なし）
- 現在地ボタン: Geolocation で現在地を表示し、近い順に 3 株を候補として下部に出す。タップで株の詳細へ（2-8）
  - ボタンは地図の右下（出典の上。拡大縮小は右上）。押したときだけ `getCurrentPosition`（`enableHighAccuracy: true`、`timeout: 10000`、`maximumAge: 30000`）で 1 回取得する。`watchPosition` で追跡しない。取得中はボタンが「取得中…」
  - 地図に現在地の点（青い丸に白い太枠。株の緑の点と見分ける。タップは受けない）と精度の円（半径 `accuracy` m）を出し、現在地へ寄せる（ズーム 19 以上）
  - 候補: 地図の下に「現在地から近い株」として 3 株（株コード、代表の茎の状態、距離「12 m」）。対象はその圃場の撤去していない株。距離は `src/lib/geo.ts` の `distanceM`、並べ替え（同じ距離は株コード順）・上位 3 件・精度の判定・エラーの文言は `src/lib/nearby.ts`。代表の茎は 出蕾済み → 栽培中 → 吸芽 → 収穫済み → その他 の順で、茎がなければ「茎なし」
  - `accuracy` が 10 m を超えたら「位置の誤差が大きい（± N m）。候補の順番は目安です」を候補の上に出す（候補は 3 株のまま）
  - 位置情報が使えないとき（拒否・取得できない・タイムアウト・非対応）は理由を地図の上に出し、地図・株のタップ・配置は普段どおり使える。拒否のときは「設定アプリ → Safari（または ホーム画面のアプリ）→ 位置情報 で許可してください」
  - 現在地は保存しない（DB にも localStorage にも）。画面を離れると消える
  - ホームの「近くの株を探す」（今週見る株の下）→ `/map?locate=1`（圃場が 1 つならその地図へ転送、複数なら圃場を選ぶ）→ `/fields/[id]/map?locate=1`。`?locate=1` のときは地図の準備ができたら自動で 1 回取得する
- 株をタップ → 株の詳細へ
- **配置モード**（設定から入る）
  - 「格子で配置」: 最初の株をタップ → 列の向きをもう1点タップ → 列数・本数・株間（既定 3m）・品種・植え付け日・苗の種類・初期葉数を入力 → プレビュー表示 → 各点をドラッグで微調整 → 確定
  - 「1株追加」: 空いている位置をタップ → 品種（既定: この圃場で最後に登録した株の品種）ほかを入力 → 確定
  - 株コードは `圃場記号-連番` で自動付番。圃場記号は圃場の設定で決める
- 格子の生成と距離計算は `src/lib/geo.ts`（単体テスト対象）

### 3. 株の詳細
- ヘッダ: コード、品種、植え付け日、由来（株分けなら元の株へのリンク）
- 茎の一覧（世代順）: 状態、累計葉数、検算のずれがあれば警告、予測収穫日（出蕾済みのとき）。タップで茎の記録入力へ
- 「吸芽を記録」: 新しい `sucker` 状態の茎を作る
- `sucker` の茎には「採用」「芽かき」「株分け」ボタン
  - 採用: 初期葉数を入力。active が3本なら不可（理由を表示）
  - 株分け: 転出先の圃場と位置を地図で指定 → 新しい株が作られる

### 4. 茎の記録入力（現場の主画面）
- 大きなボタン（`RecordButton`）で `leaves_new` を「+1 / +2」（それ以上は数字入力）。押すと累計葉数がその場で更新される。「増えていない（+0）」は控えめなリンクで、記録は残す
- 「枯葉処理」: 除去枚数
- 「現在の葉数」: 数字入力
- 「写真」: `<input type="file" accept="image/*" capture="environment">`。撮影後すぐ保存（オフラインなら端末に保持）
- 「イベント」: 出蕾（生葉数・周囲長・前回訪問日）、段数、袋掛け、摘蕾、収穫（重量）、被害（種類・程度）
- 状態が `harvested` / `removed` / `transplanted` / `lost` の茎は記録ボタンを出さず、履歴へのリンクだけ
- 記録を編集・削除する UI はない。間違えたときは「訂正」から新しい値を入れる（元の値は履歴に残る）

### 5. 施肥の一括入力
- 圃場、日付、肥料名、量、単位を入力 → 対象の株（既定は圃場の全 active な株）を一覧で確認 → 例外の株は量を個別に変える、または外す → 確定
- 株ごとに `fertilized` イベントが作られる。`batch_id` で束ねる

### 6. 圃場の設定
- 圃場の一覧（`/fields`。ログアウトもここ）と新規登録（`/fields/new`。名前、圃場記号、代表点）。代表点は地図のタップ、または緯度経度の入力
- 圃場の詳細: 土壌分析の一覧と入力（分析日、項目と値）

### 7. 予測一覧
- 週ごとの表: 収穫予定本数、見込み kg（推定が未算出の茎は本数のみ）
- 茎ごとの表: 株コード、出蕾日、予測収穫日（幅）、推定重量
- 圃場で絞り込み

### 8. 茎の履歴
- 時系列に、観測・イベント・写真（サムネイル）・推定を並べる。訂正済みの記録は打ち消し表示

## 3. 共通（UX-1 で部品化。部品は `src/components/ui/`（shadcn/ui）と `src/components/app/`）

- **画面の枠 `AppScreen`** = `PageHeader` ＋ `<main>` ＋ `BottomNav`。ログイン（画面 0）とオフライン案内（`/offline`）以外の全画面はこれで作る
- **`PageHeader`**: 左「← 戻る」（1 つ上の画面へ。例: 茎の記録 → 株の詳細 → 圃場の地図 → 圃場の詳細 → 圃場の一覧 → ホーム）、中央タイトル、右「ホーム」アイコン（`/`）。
  未同期件数のチップは `layout.tsx` の `SyncStatus` が 1 つだけ描き、ヘッダの右側（ホームの左）に重ねる。0 でも表示。タップで同期の状態（送信中 / 要確認 / 手動同期）がヘッダ直下に開く
- **`BottomNav`（下部タブ）**: ホーム `/` ／ 地図（直近に開いた圃場の地図 `/fields/[id]/map` へ直接。直近の圃場は端末に記録し、地図・株の詳細を開くと更新。未記録なら地図用の圃場選択 `/map`（強調は地図タブのまま。圃場が 1 つならその地図へ転送）。圃場選択から 1 タップで地図）／ 予測 `/forecast`（ステップ 3 まで「準備中」のプレースホルダー）／ 設定 `/fields`（圃場の一覧・追加とログアウト）。現在地のタブを強調。各タブは 64px 高（タップ領域 44px 以上）、`safe-area-inset-bottom` を空ける
- **ナビの決まり**: どの画面からも 2 タップ以内でホームへ（ヘッダのホーム、または下部タブ）。ホームからは圃場（名前のタップ）・最近開いた株（直近 5 件、端末の localStorage）・地図（下部タブ）へ 1 タップ。端末に残すこれらの情報はユーザーごと（別のユーザーでログインすると消え、ログアウトでも消える）
- **見つからない画面（404）**: 日本語の案内に、ヘッダのホームと下部タブを付ける（PWA には戻るボタンが無いので行き止まりにしない）
- **地図上の株の点**: 見た目は小さい点のまま、透明な 44px の当たり判定で包む。拡大縮小ボタンも 44px
- **記録ボタン `RecordButton`**: 現場用の大きなボタン（高さ 64px 以上、幅いっぱい）。葉数の +1 / +2 の主役に使う。「増えていない（+0）」は控えめなリンク（記録は `leaves_new = 0` として残る）
- **入力 `FormField` / `NumberField`**: ラベル＋入力＋補足＋エラー。数値は単位付き。入力欄・ボタンの高さは画面をまたいで同じ（入力 48px、ボタン 44 / 48 / 56px）
- **トークン**（`globals.css`）: primary は緑 1 色（`#2f6f3e`）、文字 16px 以上・行間広め、角丸 1 種類、間隔は 4 の倍数、屋外向けにコントラスト WCAG AA 以上
- 圃場の一覧（`/fields`）と登録（`/fields/new`）は別画面。一覧の「＋ 圃場を追加」から登録へ。登録できたら一覧へ戻る
- 入力はすべて「保存」ボタンを押さずに確定する（タップ＝記録）。誤操作対策として、イベント系は確認ダイアログ（`Dialog`）を出す
- 日付の既定は今日。過去日付に変えられる
- 文言は日本語。コード内の識別子は英語（`CLAUDE.md` の用語表）
