## 2026-10-23（初回の動作確認、iPhone の PWA）

- 株の画面からホームにすぐ戻れない（逆も） → UX-1
- テキストボックスのサイズが不揃い → UX-1
- 葉数を増やすボタンに「+0」があるのが邪魔 → UX-1（主役から外す）
- 圃場・株の名前を変更できない → UX-2
- 圃場の一覧と登録が同じ画面にあり、区切りがない → UX-1
- 通信が遅い → PERF-1
- 全体にレイアウトが素っ気ない → UX-1（shadcn/ui ＋ トークン）
